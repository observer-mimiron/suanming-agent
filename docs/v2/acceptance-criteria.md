# v2 对照版验收标准

以下只在 v1 主线完成后启用。

## M2: LangGraph 推理层

| # | 验收用例 | 预期结果 | 验证方式 |
|---|---------|---------|---------|
| M2-1 | 复杂资料输入场景 | 能正确提取和规范化出生资料 | curl |
| M2-2 | 模糊时辰 | 能返回结构化追问 | curl |
| M2-3 | 同一产品问题在 v1/v2 对比 | v2 的条件边和路由更清晰 | 人工评审 |
| M2-4 | `curl localhost:8000/docs` | FastAPI 文档可访问 | 浏览器 |
| M2-5 | reasoning flow 可视化 | 能清楚展示 planner/routing 的价值 | 人工评审 |

总体原则：

- v2 不阻塞 v1 上线和演示
- 面试时优先讲清楚 v1，再讲 v2 的对照价值
