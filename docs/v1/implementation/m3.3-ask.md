# M3.3: handleAsk 追问逻辑

**目标：** 信息不全时生成追问文案并 SSE 推送  
**时间：** 10min  
**依赖：** M3.2

---

## 步骤

- [ ] 在 `internal/orchestrator/orchestrator.go` 添加

```go
var fieldNames = map[string]string{
    "year":"出生年份","month":"出生月份","day":"出生日期",
    "hour":"出生时辰","gender":"性别",
}

func (o *Orchestrator) handleAsk(sw *sse.Writer, st *state.SessionState) error {
    sw.Send("thinking", map[string]any{
        "agent":"orchestrator","text":"正在核实出生信息...",
    })
    missing := st.MissingFields()
    names := make([]string, len(missing))
    for i, f := range missing { names[i] = fieldNames[f] }
    sw.Send("text", map[string]any{
        "content": fmt.Sprintf("请告诉我你的%s", strings.Join(names, "、")),
    })
    sw.Send("done", map[string]any{})
    return nil
}
```

- [ ] 添加 import: `"fmt"`, `"strings"`
