# M6.1: 端到端手动测试

**目标：** 5 个核心场景全部通过  
**时间：** 30min  
**依赖：** M1-M5 全部

---

## 测试场景

- [ ] **场景1: 信息不全追问**
  输入 "帮我算八字" → 追问出生年月日时和性别

- [ ] **场景2: 完整排盘**
  输入 "1990年5月20日早上8点，男。今年事业怎么样？"
  → 命盘卡片 + 知识引用 + 流式回答

- [ ] **场景3: 多轮收集**
  "帮我算八字" → (追问) → "1990年5月20日早上8点" → (追问性别) → "男" → 排盘+回答

- [ ] **场景4: 追问复用**
  排盘后输入 "感情方面呢？" → 不复算，直接回答

- [ ] **场景5: 资料变更重排**
  排盘后输入 "不对，我是女的" → 旧命盘失效，重新排盘

## 验收

- [ ] 全部 5 个场景通过
- [ ] 首个 SSE 事件在 3s 内到达
