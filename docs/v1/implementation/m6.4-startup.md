# M6.4: 启动脚本

**目标：** start.sh 一键启动所有服务  
**时间：** 10min  
**依赖：** M6.3

---

## 步骤

- [ ] 创建 `start.sh`

```bash
#!/bin/bash
set -e
echo "=== 命理大师 v1.1 ==="

if [ -z "$LLM_API_KEY" ]; then
    echo "错误: 请设置 LLM_API_KEY"
    exit 1
fi

echo "[1/2] 启动 Go 后端..."
go run ./cmd/server/ &
GOPID=$!

echo "[2/2] 启动前端..."
cd web && npm run dev &
VUEPID=$!

echo ""
echo "命理大师: http://localhost:5173"
echo "Ctrl+C 停止"
trap "kill $GOPID $VUEPID 2>/dev/null" EXIT
wait
```

- [ ] `chmod +x start.sh`

## 验收

- [ ] `./start.sh` 一键启动 Go(:8080) + Vue(:5173)
- [ ] 浏览器可访问
