# Wolke 系统吸收方案

> 评估日期：2026-06-10

---

## 差距分析

对比 wolke 系统的能力，我们当前系统缺失的关键模块：

| 模块 | wolke | 我们 | 差距 |
|------|-------|------|------|
| 日主强弱 | 4 级判断（身强/弱/旺极/弱极） | ❌ 无 | **核心缺失** — 决定用神方向 |
| 用神系统 | 扶抑+调候+从格+专旺 | ❌ 无 | **核心缺失** — 影响所有分析 |
| 调候分析 | 季节寒暖燥湿 | ❌ 无 | 中等 — 提升准确度 |
| 格局分析 | 正常格局+特殊格局 | ❌ 无 | 中等 — 区分命格层次 |
| 大运吉凶 | 明确的好坏判断规则 | 仅输出 raw data | **高价值** — LLM 依赖此信息 |
| 输出模板 | 完整的 markdown 模板 | LLM 自由发挥 | 低 — 格式化输出 |

## 实施方案

### P0: 添加用神计算工具 (internal/tools/yongshen.go)

**目标**：输入命盘，自动输出日主强弱 + 用神喜忌

实现逻辑（来自 wolke）：
1. 判断日主强弱
   - 月令：日干在月支的旺衰（得时/失时）
   - 通根：日干在地支的根数
   - 生扶：天干+地支藏干中生扶日主的数量
   - 结论：身强(得时+多根+多扶) / 身弱 / 身旺极 / 身弱极
2. 根据强弱确定用神
   - 身强 → 用神=食伤/财星/官杀
   - 身弱 → 用神=印星/比劫
   - 身旺极 → 顺其旺势
   - 身弱极 → 从格判断
3. 调候修正
   - 冬月 → +火
   - 夏月 → +水

**输出**：
```json
{
  "day_master_strength": "身弱",
  "yong_shen": ["水","木"],
  "xi_shen": ["金"],
  "ji_shen": ["火","土"],
  "tiao_hou": "需火调候",
  "special_pattern": null
}
```

**工作量**：~100 行 Go 代码，基于已有 lunar-go 数据

### P1: 添加大运吉凶分析 (internal/tools/dayun-analyzer.go)

**目标**：对每个大运判断吉凶

逻辑：
1. 大运天干十神 + 地支藏干 → 判断是比劫/食伤/财/官杀/印星运
2. 与用神对比 → 用神运=吉，忌神运=凶
3. 检查大运与原局的冲合刑害

**输出**：
```json
[
  {"age":"27-36","ganZhi":"壬申","type":"正财运","quality":"吉","reason":"财为用神"},
  ...
]
```

**工作量**：~80 行 Go 代码

---

### P2: 流年分析工具 (internal/tools/liunian.go)

**目标**：输入年份，输出该年干支+与大运/原局的冲合刑害关系

参照 wolke 的规则：
- 流年干支十神
- 与大运的关系（并临/相冲/天克地冲）
- 与原局四柱的冲合刑害
- 与年柱的犯太岁关系

**输出**：
```json
{
  "year": 1996,
  "yearGanZhi": "丙子",
  "tenGod": "正印",
  "clashes": ["子午冲(日支)"],
  "harmonies": ["子丑合(月支)"],
  "taiSui": "子午冲，冲动年支",
  "dayunRelation": "吉运遇吉年"
}
```

**工作量**：~120 行 Go 代码

## 优先级和时间估算

| 优先级 | 模块 | 工作量 | 影响 |
|--------|------|--------|------|
| **P0** | 用神计算 | 1h | 所有分析的质量基础 |
