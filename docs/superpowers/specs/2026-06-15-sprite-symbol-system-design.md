# 命理大师 — 统一符号系统设计

> **目标**: 用有真实依据的符号语言替代程序员画的几何图标，三个系统（五行/九星/八门）各自采用适合的设计语言，统一视觉框架。

**设计原则**: 微型象征场景 + 圆角卡片框 + 五行色系 + 塔罗牌式有机线条 + 成人卡通插画感

---

## 三个系统 · 三种设计语言

| 系统 | 数量 | 设计语言 | 依据 |
|------|------|----------|------|
| **五行** | 5 | 微型自然景观 | 木火土金水是物质元素，自然界有标准形象；融入八字五德（仁礼信义智） |
| **九星** | 9 | 夜空星座图 | 九星 = 北斗九星，星座连线是最正宗的天文语言 |
| **八门** | 8 | 人事象征场景 | 八门不是门，是人事状态（开=开创/休=修养/生=生机...），需场景叙事 |

### 统一框架参数

| 参数 | 值 |
|------|-----|
| **卡片形状** | 圆角矩形 (rx: 12-17px) |
| **背景** | 线性渐变 (上亮下暗, 五行色系) |
| **边框** | 1.1-1.2px, 五行色系中期色 |
| **线条风格** | stroke-linecap:round, 1.0-2.4px, 有机手绘感 |
| **配色** | 低饱和暖调五行色 |

---

## 五行色系

```
木: bg=#e2eedc border=#7a9e7e main=#7a9e7e (青绿 · 仁)
火: bg=#fae4d8 border=#cc9888 main=#c47a6a (赤 · 礼)
土: bg=#f0e6d2 border=#c4a980 main=#b8956a (黄褐 · 信)
金: bg=#f4eed8 border=#c4a96a main=#b8956a (暖金 · 义)
水: bg=#dee8f2 border=#7a9ab8 main=#6b8aa8 (灰蓝 · 智)
```

## 1. 五行 (ElementSprite) — 68px

微型自然景观插画，每幅包含 15-25 个视觉元素，有前景/中景/背景层次。

### 木 · 仁
- 参天大树（主干+多级树枝）
- 深根系统（地下）
- 阔冠叶片簇（多个 circle 叠加）
- 新芽/果实小点
- 落叶
- 远山 + 地平线 + 地面小草

### 火 · 礼
- 篝火柴堆底座
- 四层火焰（外焰→中焰→内焰→侧焰）
- 太阳光芒光晕（同心圆+放射线）
- 15+ 飞散火星
- 地面弧线

### 土 · 信
- 三层远中近山脉
- 雪顶
- 山脊线/梯田线
- 山顶红日+光环
- 松树点缀
- 白云

### 金 · 义
- 中央剑锋（庚金 — 刚毅）
- 左右晶簇（辛金 — 精致）
- 切面/刃线
- 碎小晶
- 闪光点
- 岩床底座

### 水 · 智
- 崖壁瀑布流
- 深潭水面
- 三层同心涟漪
- 主水滴（高光）
- 多个小雨滴
- 水面浪花

| 天辅 | 巽 | 木 | 双弧星轨 |
| 天禽 | 中 | 土 | 十字准星 |
| 天心 | 乾 | 金 | 六芒星阵+中心亮星 |
| 天柱 | 兑 | 金 | 双柱星列 |

## 3. 八门 (SpriteDoor) — 48px

人事象征场景，不再画门。尺寸 48px, 圆角 rx=12px。

| 门 | 八卦 | 五行 | 场景 | 画面 |
|----|------|------|------|------|
| 开门 | 乾 | 金 | 开创通达 | 朝阳升出地平线+上下光柱 |
| 休门 | 坎 | 水 | 休养生息 | 弯月+静水面+倒影涟漪 |
| 生门 | 艮 | 土 | 生机勃发 | 种子破土+左右嫩叶 |
| 伤门 | 震 | 木 | 破损伤害 | 圆环碎裂+裂痕 |
| 杜门 | 巽 | 木 | 堵塞隐藏 | 方框+X封印+中心锁 |
| 景门 | 离 | 火 | 文采展现 | 方窗框+远山弧线+太阳 |
| 死门 | 坤 | 土 | 终结静止 | 落日半沉地平线 |
| 惊门 | 兑 | 金 | 惊恐突变 | 竖线+横突刺 |
