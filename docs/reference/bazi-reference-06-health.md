## 三、疾病预测四大原则

1. **过弱的五行**：该五行代表的脏腑有先天隐患，逢大运流年引动即发病。"无者怕见面，一见面就遭克"
2. **过旺的五行**：旺极本身即是病。被过旺五行所克的五行也代表疾病。被过旺五行所生的也会"受病"——土多金埋、金多水浊、水多木漂、木多火塞、火多土焦
3. **被冲克的五行**：某五行被冲克受伤，所代表的脏腑器官必有病伤
4. **寒暖燥湿失衡**：命局过寒（金水多生于冬）、过燥（火土多生于夏）都会对应相应疾病

## 四、分五行断病详细断语

### 木（肝胆）

**基本对应**：甲为胆，乙为肝，木也代表毛发、交感神经、四肢。

**经典断语**：

- "水多木漂，甲木弱极，易患脾湿之病"，严重者皮肤萎缩，轻者秃顶
- "水多木漂，乙木弱极，易患肝火虚热或肝肿大"，常伴口臭、眼屎多
- "金水多而木腐，甲木弱极缺火疏通，易患胆囊结石"
- "金水多而木腐，乙木弱极缺火疏通，易患肝硬化"
- "火多木焚，木气弱者，肝虚或目赤"
- "土多木折，燥土过多，发易分叉或断裂"
- "木被金伤，筋骨腰肋疼痛"——金木相战主筋骨
- "甲乙无根、怕逢申酉、杀合逢此、双目定瞽"
- "甲申乙酉，小儿肝经风病"
- 柱中水多，支见子卯刑，卯木不透干，必有肝病
- 卯木被酉金冲克，无救定有肝胆病

### 火（心、小肠）

**基本对应**：丙为小肠，丁为心，火主血脉、神志、眼目。

**心脏疾病断语**：

- "丁火强水压迫，有高血压或心跳过快"
- "木多火窒，丁火弱极，易患心肌梗塞"
- "丁火强旺土气弱极，血压低、脉搏缓、常喘大气"
- "丁火弱入库，易患心脏病；再逢刑冲克害，因心脏病开刀"
- "丁火弱土气强，必有贫血"

**眼目、脑神经断语**：

- "火遭水克，眼目昏暗"
- "丙火过弱，涉及视力眼疾或脑神经衰弱"
- "木多火窒，丙火弱极，脑神经亢奋有神经质"
- "亥子加巳午，眼疾"
- "丙辛合，防近视"

**经典古诀**：

- "巳午庚辛，男女病多心血"
- "丙丁岁月，壬癸遇，眼目有疾"
- "三丁二丙到金，口舌生疮"

### 土（脾胃）

**基本对应**：戊为胃，己为脾，土主肌肉、皮肤、口唇。

**胃病断语**：

- "土虚乘木旺之乡，脾伤定论"
- "戊土太旺或太弱易生胃病"
- "木旺土弱，胃病"
- "水多土荡，胃病、胃出血"
- "火多土焦，胃炎、胃溃疡"
- "辰戌相冲，胃受伤"
- "戊土弱、金神太旺，胃下坠"

**皮肤病断语**：

- "水多土虚，易皮肤过敏"
- "湿土太多或土遭水侵，湿疹、皮肤炎"
- "丑未冲，脾病、中气不足"

### 金（肺、大肠）

**基本对应**：庚为大肠，辛为肺，金主骨骼、牙齿、呼吸系统。

**肺部疾病断语**：

- "金弱遇火旺，血疾无疑"——肺炎、咳血
- "土重埋金，辛金弱极且湿土重，易患肺气肿、肺结核"
- "燥气过重，易感染肺炎、肺痨"
- "辛金弱遇强水泄秀过甚，感冒先发烧后浓痰咳嗽"
- "水旺辛金弱或土强埋金，支气管炎、鼻塞、咳嗽"
- "金水伤官，寒则咳嗽、热则痰火"

**骨骼牙齿断语**：

- "金气弱遇强水强木泄盗，骨骼脆而不硬朗"
- "强木冲庚金或强火克庚金，主骨伤骨疾"
- "强木冲辛金或强火克辛金，口腔病或矿物质缺乏"
- "湿土埋金或水多金沉，风湿病、关节炎、软骨病"

**古诀**："辛卯庚寅，尤忌大人劳骨病"

### 水（肾、膀胱）

**基本对应**：壬为膀胱，癸为肾，水主生殖系统、泌尿系统、耳。

**肾病断语**：

- "金水枯伤，肾必虚"
- "水旺木漂或水弱土盛，膀胱、肾脏病"
- "癸水入库又逢刑冲克破，或逢旺火熏蒸，肾虚亏"
- "冬月生水气冻结，不见木火，肾水冻结不通，阳痿早泄"
- "壬水弱极，遇强土滞水，膀胱结石"
- "癸水入库逢旺火熏蒸，子宫、卵巢机能衰弱"

**古诀**："六癸还生，休囚肾病"

## 五、综合疾病断语

### 高血压、脑心血管病

- 四柱火土旺、金水弱，中老年易患高血压
- 甲木旺，宜泄不宜克，逢克易脑溢血
- 金木相战，神经受损、筋骨断折

### 糖尿病

- 四柱见金火相战、燥土埋金、金脆水枯，患病率90%以上
- 有庚午或辛巳，火旺土焦，患病率90%以上

### 伤灾残疾

- 七杀透干、官杀同透，头面带伤破相
- 伤官、七杀、阳刃并显，肢体恐有残伤
- 庚辛申酉全见，主血光伤残
- 申巳双加遇刑，臂肢有患

### 阳虚阴虚判定

- 水旺火虚 → 阳虚（需补火，喜木火）
- 火旺水虚 → 阴虚（需补水，喜金水）

## 六、疾病应期判断

1. 原局有隐患五行，大运流年引动则发病。如果某五行在原局中就弱而受克，当大运或流年再来克害时，必定发病
2. 某五行旺极，走旺运反而成病。如原局火旺土燥，再走火土大运，肺部或肾脏易出问题
3. 冲刑之年易诱发外伤、手术、急病。特别是原局就有刑冲组合，流年引动时
4. 用神被大运流年冲克，对应脏腑也易生病
