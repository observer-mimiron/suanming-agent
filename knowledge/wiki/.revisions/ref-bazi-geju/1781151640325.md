## 一、格局概述

格局是八字命理中對命盤整體結構的歸納，用以概括命主的人生基本框架與層次高低。其核心判斷始於月令，即「月令提綱最要明」。

核心分析口訣：「月令提綱最要明，透干定格看分明。正格八種分清楚，特格從專各不同。格局成敗看配合，高低貴賤在其中。」

三大關鍵：**月令為本**、**透干為憑**、**配合定高低**。

## 二、正格体系

正格以月令所藏天干「透出」與否來決定格局類型，總共八種。

善神（财、官、印、食）顺用，不善神（杀、伤、枭、刃）逆用。

### 2.1 正官格

**定义**：月令透正官，如甲見辛、乙見庚。

**成格条件**：
- 月令透正官，且正官不被合、沖、剋
- 日主不能過弱
- 官星通根得令，財印兩得相扶，四柱不見傷官七殺

**层次（由高至低）**：官印相生（最佳）→ 財官相生（次佳）→ 官星獨清

**破格因子**：傷官見官、官殺混雜、官星被合去

**喜**：身旺、印綬、食神、以財為引

**忌**：身弱、七殺、傷官、刑沖、貪合、入墓

**口诀**：「家里藏官便是福，无伤无破喜透出。财来相济印来助，今生今世名利足。」

### 2.2 七杀格

**定义**：月令透七杀，如甲見庚、乙見辛。有制為偏官，無制為七殺。

**成格条件**：
- 月令透七殺，且須有食神或印星制化
- 日主不過弱
- 殺印相生格：殺生印，印生身，生化有情
- 食神制殺格：食神有力制殺

**层次**：食神制殺 → 殺印相生 → 羊刃合殺

**破格**：殺重身輕無制、制殺太過、殺被合去、七殺逢財無制（財生殺攻身）

**关键规则**：
- 殺強制弱 → 走制殺之地（食傷運）或印鄉
- 身殺兩停 → 取印地化殺，或走食傷制殺地
- 身強殺弱 → 走七殺生旺之鄉
- 身弱殺強 → 走日主生旺之鄉（比肩、劫財、祿刃）

**口诀**：「生来七杀月中藏，命中手足定见伤。此命就该往外走，出门见贵有人帮。」

### 2.3 财格（正财格 / 偏财格）

#### 正财格

**定义**：阳克阴、阴克阳（甲见己、乙见戊）

**喜**：身旺、印、食神、逢财看官

**忌**：身弱、比肩、羊刃、空绝、冲合

#### 偏财格

**定义**：阳克阳、阴克阴（甲见戊、乙见己）

**喜**：身旺、印、食神、喜见官星（偏财喜见官星，正财不喜）

**忌**：身弱、羊刃、比劫、空绝、冲合、怕透干

#### 成格条件

| 格局形式 | 条件 |
|-----------|------|
| 财旺生官格 | 财格带官旺，身强 |
| 食神生财格 | 财格带食神生财，须身强带比 |
| 财格配印 | 财印需隔开，互不相碍 |
| 用财喜比格 | 财旺身稍弱，以比肩助身 |

#### 破格

财轻而比劫根重 → 格败；财格透七杀 → 格败（财生杀攻身）；财多身弱行官财地 → 祸患百出

### 2.4 印格（正印格 / 偏印格）

#### 正印格

**定义**：生我，阴阳异性（如甲见癸）

**特点**：惟印绶喜身弱（印多则性格清孤，只喜一位）

**喜**：食神、天月德、七杀、逢印看杀、以官为引

**忌**：刑冲、伤官、死墓、财星破印

#### 偏印格（枭神）

**定义**：生我，阴阳同性（如丙见甲），能克破食神，又称倒食

**特点**：最忌食神（枭神夺食），正印却喜见食神

**喜**：身旺、天月德、伤官、正财

**忌**：刑冲、食神、身衰枭旺

#### 成格条件

| 格局形式 | 条件 |
|-----------|------|
| 用印喜官格 | 印轻逢官杀（官印相生） |
| 用印喜食格 | 身印两旺，有食伤泄秀 |
| 弃印就财格 | 印多而逢财透（财破印为用） |

#### 破格

印轻逢财（财破印）、身强印重透杀、印重身强而透杀

**口诀**：「用之偏印怕谁伤，儿来激怒杀来帮。最喜偏财和杀比，三贤和睦富贵长。」

### 2.5 食神格

**定义**：月令藏食神且透干（甲见丙、乙见丁）

**喜**：身旺、食神生财、食神制杀、以比肩为助

**忌**：枭神夺食（偏印）、食伤过旺、官杀混杂

**成格**：
- 食神生财（身强有力）
- 食神制杀（无财）
- 弃食就印（有杀印须透印）

**破格**：逢枭神；食神生财而透杀

**口诀**：「用之食神怕谁伤，财能护卫禄能帮。最怕枭杀同来并，非灾即病入牢房。」

### 2.6 伤官格

**定义**：月令藏伤官且透干（甲见丁、乙见丙）

**喜**：身旺、财星、印绶（伤官佩印）、伤官伤尽（四柱无官）

**忌**：身弱、无财、刑冲、官星（伤官见官，为祸百端）

**成格**：
- 伤官生财（身强）
- 伤官佩印（伤旺印有根）
- 伤官伤尽（四柱无官星，身旺财旺或印旺）

**破格**：非金水伤官而见官星；伤官配印而伤轻身旺

**特殊**：金水伤官例外可见官；伤官最喜行财运，不喜行官乡

### 2.7 阳刃格与建禄月劫格

| 格局 | 条件 | 喜 | 忌 |
|------|------|-----|-----|
| 阳刃格 | 月令为日主帝旺 | 透官杀带财印 | 无官杀 |
| 建禄月劫 | 月令为日主临官/禄位 | 透财官食伤 | 无财官而透杀印 |

**阳刃对应**：甲→卯、乙→寅、丙戊→午、丁己→巳、庚→酉、辛→申、壬→子、癸→亥

**口诀（阳刃）**：「家里藏刃更不强，喜有偏官做武郎。但逢刑冲破害地，一片红云见血光。」

## 三、特殊格局

### 3.1 从格（身弱极）

日主極弱，無根無助，順從八字中最強的五行。

| 类别 | 条件 | 特点 |
|------|------|------|
| 从财格 | 日主极弱，财星极强，无印比生扶 | 顺从财运，易得财富 |
| 从官格 | 日主极弱，官星极强，无印比生扶 | 顺从权威，利仕途 |
| 从杀格 | 日主极弱，七杀极强，无印比生扶 | 刚强果断，武职缘分 |
| 从儿格 | 日主弱，食伤极强 | 才华横溢，顺天赋发展 |

共同特质：需顺从强势五行，放弃自我主张。

### 3.2 专旺格（身旺极）

日主極旺，八字中該五行獨霸，共五類：

| 格局 | 五行 | 条件 | 特质 |
|------|------|------|------|
| 曲直格 | 木 | 甲乙日主，寅卯月，地支全木局 | 仁爱正直，利教育文化 |
| 炎上格 | 火 | 丙丁日主，巳午月，地支全火局 | 热情光明，声名显赫 |
| 稼穑格 | 土 | 戊己日主，辰戌丑未月，地支全土局 | 稳重厚实，利房地产 |
| 从革格 | 金 | 庚辛日主，申酉月，地支全金局 | 果决刚毅，利军警法律 |
| 润下格 | 水 | 壬癸日主，亥子月，地支全水局 | 智慧变通，利贸易航运 |

取用原则：顺其旺势，以旺神为用。

### 3.3 杂格

- **财滚滚格**：食伤旺 + 财星旺，形成连续生财，以才华致富
- **伤官合杀格**：伤官与七杀相合，特点为"化敌为友，转危为安"

## 四、格局高低判定

**高格局特征**：格局成立、用神旺相得用、干支配合有情、无破坏因素

**低格局特征**：格局不成、用神弱或受制、干支冲突无情、格局被破坏

### 十大破格要素总览

| 格局 | 破格条件 |
|------|----------|
| 正官格 | 逢伤官、冲、刑、克 |
| 财格 | 财轻而比劫根重 |
| 印格 | 印重身强而透杀 |
| 食神格 | 食神生财而透杀 |
| 七杀格 | 七杀逢财无制 |
| 财格透杀 | 有制也败 |
| 伤官格 | 非金水伤官而见官 |
| 伤官配印 | 伤轻身旺 |
| 阳刃格 | 无官杀 |
| 建禄月劫 | 无财官而透杀印 |

### 败中救应

- 原局破格不重 + 大运修格局 → 运过打回原形，人生大起大落
- 大运部分修复 → 多成多败
- 原局破格重 + 大运凶 → 贫贱难免

## 五、用神体系

### 5.1 核心定义

- **用神**：对命格最具助益的五行或十神
- **喜神**：辅助用神发挥作用的五行
- **忌神**：对命格杀伤力最大的五行
- **仇神**：辅助忌神的五行
- **闲神**：影响力较小的五行

### 5.2 取用基本法则

| 日主状态 | 方向 | 用神类型 |
|----------|------|----------|
| 身强 | 泄、耗、克 | 食伤、财星、官杀 |
| 身弱 | 生、助 | 印星、比劫 |
| 身旺极 | 顺势 | 比劫、印星 |
| 身弱极 | 从势 | 所从之神 |

核心大纲：「身强宜泄宜克宜耗，身弱宜生宜助宜扶。从强格局顺势不可逆，从弱格局随流莫强扶。」

### 5.3 身强三条路径

**① 食伤泄秀**：日主能量过剩时，通过食神伤官将之转化为才华。喜食伤与财星，忌印星克制食伤。

**② 财星耗身**：日主需付出精力去克制财星，消耗旺气。喜财星与食伤（生财），忌比劫夺财。

**③ 官杀制身**：官杀克制日主，使其有所收敛，形成纪律格局。喜官杀与财星（生官杀），忌印星化解官杀。

### 5.4 身弱两条路径

**① 印星生身**：印星持续给予日主支持，增强力量。喜印星与官杀（生印），忌财星破坏印星。

**② 比劫助身**：与日主同五行，直接增强力量，形成互助格局。喜比劫与印星，忌官杀克制比劫。

### 5.5 四大取用法则

| 法则 | 条件 | 方法 |
|------|------|------|
| **扶抑** | 身强/身弱 | 身强则抑（官杀·食伤·财），身弱则扶（印·比劫） |
| **调候** | 命局过寒/过热 | 寒用火暖、热用水润 |
| **通关** | 两行相战 | 取通关五行（如金木交战引水通关） |
| **病药** | 命局有病 | 以制病之五行为用 |

### 5.6 调候用神

根据出生季节的寒暖燥湿来选取。关键原则：**调候有时优先于扶抑**。

| 情况 | 问题 | 调候用神 |
|------|------|----------|
| 冬月生 | 寒冷 | 火（暖命） |
| 夏月生 | 燥热 | 水（润命） |
| 金水太旺 | 寒湿 | 木火 |
| 木火太旺 | 燥热 | 金水 |

### 5.7 用神受损四种情况

- 被合 → 力量减弱
- 被冲 → 力量受损
- 被克 → 难以发挥
- 入墓 → 力量受困
