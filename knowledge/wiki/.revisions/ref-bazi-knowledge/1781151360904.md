## 五、日主旺衰判断

### 5.1 三步法（按权重递减）

**第一步：得令（权重约 50%）**

| 条件 | 判定 |
|------|------|
| 月令与日主同五行（当令） | 强力得令 |
| 月令生日主（相气） | 中等得令 |
| 月令克/泄/耗日主 | 失令 |

**第二步：得地（权重约 30%）**

看地支中是否有日主的根气：
- **强根**：日主禄或帝旺位（甲见寅卯、丙见巳午等）
- **中气根**：藏干中以中气存在（甲见亥藏甲等）
- **弱根**：库根（甲见未等）
- **无根**：地支全然不见同类五行

**第三步：得势（权重约 20%）**

天干上印星和比劫的帮扶数量 vs 克泄耗数量。

### 5.2 量化打分法

```
总分 = 月令分 + 根气分 + 帮扶分 - 克泄耗分
```

| 总分 | 判定 | 喜用方向 |
|------|------|----------|
| ≥ 60 | 身旺 | 喜克泄耗（官杀、食伤、财星） |
| 41~59 | 中和 | 平衡为佳 |
| ≤ 40 | 身弱 | 喜生扶（印星、比劫） |
| 极弱无扶 | 从弱格 | 顺其旺势，不扶日主 |
| 极旺无制 | 从旺格 | 顺其旺势，不宜克制 |

### 5.3 快速判定口诀

```
得令+得地+得势 = 极旺
得令+得地 或 得令+得势 = 身旺
失令+得地+得势 = 身旺（仍有根基）
失令+得地+失势 或 失令+失地+得势 = 身弱
失令+失地+失势 = 极弱
```

### 5.4 特殊格局

当月令两次受伤、或被强克合化时，需重新评估。地支三合三会局成立时五行力量质变，优先考虑。

## 六、格局体系（正八格）

以《子平真诠》为核心依据。

### 6.1 取格原则

**格局专求月令**：
1. 以月令地支本气（藏干主气）定格局
2. 月令不透时，看透出天干者立格
3. 三合三会成党，以该气势取格

### 6.2 正八格总览

| 格局 | 性质 | 顺用/逆用 | 核心理念 |
|------|------|-----------|----------|
| 正官格 | 贵气之神 | 顺用 | 喜财印辅助，忌伤官、刑冲合 |
| 七杀格 | 凶神 | 逆用 | 需食伤制或印化 |
| 财格 | 养命之源 | 顺用 | 喜食伤生、官星护卫 |
| 印格 | 生身之物 | 顺用 | 喜官杀生、食伤泄秀 |
| 食神格 | 福气之神 | 顺用 | 喜生财、制杀 |
| 伤官格 | 才华之神 | 逆用 | 需配印或生财 |
| 阳刃格 | 极旺之气 | — | 需透官杀带财印 |
| 建禄月劫 | 中和 | — | 需透财官食伤 |

### 6.3 十大破格要素

| 格局 | 破格条件 |
|------|----------|
| 正官格 | 逢伤官、冲、刑、克 |
| 财格 | 财轻而比劫根重 |
| 印格 | 印重身强而透杀 |
| 食神格 | 食神生财而透杀 |
| 七杀格 | 七杀逢财无制 |
| 财格透杀 | 有制也败 |
| 伤官格 | 非金水伤官而见官 |
| 伤官配印 | 伤轻身旺 |
| 阳刃格 | 无官杀 |
| 建禄月劫 | 无财官而透杀印 |

### 6.4 败中救应

- 原局破格不重 + 大运修格局 → 运过打回原形
- 大运部分修复 → 多成多败
- 原局破格重 + 大运凶 → 贫贱难免

### 6.5 核心纲领

> 善神顺用（财、官、印、食），不善逆用（杀、伤、枭、劫）。成格高低取决于"有情无情、有力无力"——相神与格神的配合是否紧密、有根气。

## 九、大运与流年

### 9.1 大运排法

| 年干 | 性别 | 方向 |
|------|------|------|
| 阳年（甲丙戊庚壬） | 男 | 顺排 |
| 阳年 | 女 | 逆排 |
| 阴年（乙丁己辛癸） | 男 | 逆排 |
| 阴年 | 女 | 顺排 |

> **顺排**：从月柱向后推。如月柱乙亥 → 丙子 → 丁丑...
> **逆排**：从月柱向前推。如月柱乙亥 → 甲戌 → 癸酉...

### 9.2 起运岁数

> 核心：3天 = 1岁，1天 = 4个月，1时辰 = 10天

- 顺排：从生日顺数到下一个**节**，天数 ÷ 3
- 逆排：从生日逆数到上一个**节**，天数 ÷ 3
- 只用12个"节"，不用"气"

### 9.3 胎元与命宫

**胎元**：月柱天干顺推一位，地支顺推三位。代表先天禀赋、根基。

**命宫**：
1. 从子位起正月逆推至生月，得地支位
2. 以该位设为生时，顺数至卯，得命宫地支
3. 用五虎遁法定命宫天干

### 9.4 岁运关系

| 关系 | 含义 |
|------|------|
| 战 | 岁运相克（运丙克岁庚） |
| 冲 | 岁运相冲（子运午年） |
| 和 | 岁运相合（庚运乙年） |
| 好 | 岁运同类（丙运巳年） |

| 大运 | 流年 | 结果 |
|------|------|------|
| 吉 | 吉 | 大吉 |
| 吉 | 凶 | 虽有凶，不致大凶 |
| 凶 | 凶 | 凶不可免 |
| 凶 | 吉 | 吉凶互见 |

## 附录：解读提示词框架（Prompt Framework）

AI 解读八字时建议按以下流程展开：

1. **排盘确认**：确认四柱、十神、五行分布
2. **日主定位**：判断日主旺衰（得令/得地/得势）
3. **格局取定**：以月令定格局，判断成格/破格
4. **用神选取**：扶抑→调候→通关→病药，确定喜用神与忌神
5. **十神组合**：关键十神搭配及含义
6. **神煞点缀**：核心神煞（天乙/桃花/驿马/羊刃/华盖）
7. **大运趋势**：当前大运与下一步大运的吉凶方向
8. **流年提示**：当前流年与命局的互动
9. **专项分析**：性格、事业财运、感情婚姻、健康
10. **总结**：命局层次总评 + 趋吉避凶建议

> 注意：解读时应强调命理学是传统文化研究，仅供参考，不宜作为人生决策的唯一依据。

## 十四、解读话术与批命模板

> 以下断语需结合命局整体旺衰、喜忌综合判断，不可孤立套用。

### 14.1 性格解读

**按日干断**：
- 甲木人：正直上进、有责任感，成长慢但后劲足
- 丙火人：热情开朗、充满感染力
- 戊土人：稳重诚信、如大地承载万物
- 庚金人：刚毅果断讲义气、有锋芒需打磨
- 壬水人：智慧灵活、顺势而为

**按十神断**：
- 伤官太重无官星制 → 恃才傲物、不服管
- 命带魁罡 → 嘴硬心软、性子刚烈
- 七杀伤官同透 → 性格冲动，好勇斗狠
- 偏印旺 → 洞察力超强，适合科研玄学，但易孤僻
- 四柱纯阳 → 性格如烈火，直率冲动

### 14.2 事业财运

**事业核心逻辑**：「逢官看财，逢财看食，逢煞看印，逢印看官」

- 考试升学以官星为准，官为喜则考运佳
- 伤官配印 → 才华+学识兼备，格局清贵
- 财官印顺生链 → 有资源、识人脉、稳步上升
- 官杀混杂 → 冲掉合掉一个，反得事业得位
- 七杀制化得当 → 敢闯敢拼，决策果断，中年后成大器

**财运断语**：
- 财星旺、日主有根 → 走身旺运必发财
- 身弱难任财 → 赚钱辛苦、攒不住钱
- 日坐财库（壬戌、丁丑、戊辰、辛未） → 先天聚财守财潜质
- 比劫夺财 → 财星受损，防因友破财

### 14.3 婚姻感情

**男命**：
- 夫妻宫为喜用 → 妻子贤良，能帮衬
- 妻宫藏比劫 → 感情淡薄，日主强则克妻
- 财星过旺身弱 → 多半怕老婆
- 财星衰弱身旺 → 性格刚直，自己说了算

**女命**：
- 月柱伤官透干 → 夫妻缘分浅
- 日支坐伤官 → 感情不和，经常争执
- 夫宫逢冲 → 初恋多失败，头婚不顺利
- 官杀混杂 → 感情不专，多婚之象
- 食伤过旺 → 才华出众但克夫

### 14.4 健康

| 五行受克 | 对应疾病 |
|----------|----------|
| 木受克太过 | 肝胆、神经、筋骨 |
| 火受克太过 | 心脏、血液、小肠 |
| 土受克太过 | 脾胃、消化、肌肉 |
| 金受克太过 | 肺、呼吸道、大肠 |
| 水受克太过 | 肾、膀胱、妇科、泌尿 |

- 八字太热 → 多痰；八字太冷 → 多咳
- 日主泄气太过 → 神经衰弱
- 日支坐长生 → 身体健康、寿命长（忌刑冲）
- 火炎土燥 → 皮肤病；男命子嗣单薄

## 十五、盲派铁口直断规则

> 盲派以"组合定式+宫位定位+星神定性+应期锁定"四维逻辑快速断命。

### 15.1 组合定式（触发规则）

| 组合 | 触发条件 | 直断 |
|------|----------|------|
| **比劫夺财** | 比劫紧贴财星，或比劫旺财星弱 | 合伙破财、借钱不还、被人坑 |
| **伤官见官** | 伤官与正官同现，无财通关、无印制伤 | 顶撞领导、惹官非、辞官、女命离婚 |
| **枭神夺食** | 偏印紧贴食神，食神弱 | 抑郁、想不开、失业、子女不孝 |
| **财星破印** | 财星旺克印星，印星弱 | 因财失义、为赚钱误学业、母亲生病 |
| **官杀混杂** | 正官七杀同现 | 感情混乱、工作换不停 |
| **食神制杀** | 食神有力制七杀 | 以才华化解压力，律师/咨询类职业 |
| **伤官配印** | 伤官旺+印有根 | 文采斐然，作家/设计师/文人 |
| **杀印相生** | 七杀生印、印生身 | 化煞为权，军官/高管 |

### 15.2 宫位定位

同组合在不同宫位的不同解读（以"比劫夺财"为例）：

| 宫位 | 断语 |
|------|------|
| 年柱 | 祖业破败、父亲被人坑、家里钱留不住 |
| 月柱 | 兄弟朋友借钱不还、同事抢单、合伙散伙 |
| 日支 | 配偶花钱大手大脚、婚姻为钱吵架 |
| 时柱 | 被下属坑、投资被骗、子女败家 |

### 15.3 应期锁定

| 方法 | 机制 | 示例 |
|------|------|------|
| **填实法** | 原局缺某字，流年填上 | 原局伤官无正官，流年见正官→伤官见官事发 |
| **冲开法** | 原局库被冲 | 财库在辰，戌年冲开→发财或破财 |
| **合动法** | 流年合静宫位 | 流年合夫妻宫→结婚或离婚 |
| **刑动法** | 流年补全三刑 | 原局寅巳缺申，申年补全→官非伤病 |
