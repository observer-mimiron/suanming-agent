## 二、官运详断

### 有官运的十大标志

1. 官为用神，旺而逢生，有根有源、透干、有情，靠近日主 → 有官且官职显赫
2. 官为忌神，弱而受制，休囚无力，远离日主 → 有官且官职较大
3. 身弱命局不现官星 → 有官
4. 身弱官为忌神，官生印、印生身 → 有官
5. 身弱官杀为忌，被伤官食神合制得宜 → 有官
6. 从强格不见官星 → 有官
7. 从弱格官星起好作用 → 有官
8. 化格中，阴日干合化成官星 → 为官命
9. 不论喜忌，官星起到好作用 → 都有官
10. 权刃双显停均 → 位至王侯

### 无官运的八大标志

1. 官为用神弱而受制，休囚无力，无根无源 → 无官
2. 官为忌神旺而逢生，有根有源，靠近日主 → 无官且防官灾
3. 身旺命局官星不现 → 无官
4. 身旺官为忌，印化官杀 → 无官
5. 身弱官杀混杂无制 → 无官
6. 身旺官杀弱而被制 → 无官
7. 从强格官杀有根 → 无官且有官灾
8. 化格中官星为忌而旺 → 无官且有官灾

## 三、财运详断

### 财气通门户判断法

> 《滴天髓》："何知其人富，财气通门户"

| 条件 | 结果 |
|------|------|
| 日干偏旺/从弱 + 财星为用 + 明现逢生 | 富命，越生越富 |
| 日干偏旺/从弱 + 财星为用 + 明现受制 | 穷命，越制越穷 |
| 日干衰弱/从强 + 财星为忌 + 明现受制 | 富命，越制越富 |
| 日干衰弱/从强 + 财星为忌 + 明现逢生 | 穷命，越生越穷 |
| 日干偏旺/从弱 + 不见财星 | 非富命（需看组合） |
| 日干衰弱/从强 + 不见财星 | 非穷命（需看组合） |
| 阳日干化气成功组合佳 | 富命，财星越旺越富 |

### 财星特断

- 身旺偏财旺，无空破 → 巨商之命
- 身旺偏财旺，带空破 → 小商人或善外交辞令
- 财多身弱，比劫为用 → 适合与人合伙经营
- 偏财遇伤官 → 宜刺激性、投机性、冒险性事业
- 有财星和驿马 → 宜交通、运输、买卖、资讯业
- 财库宜静忌动：财库受冲→破财；运冲财库→破财概率大增

> "你的八字中，（官星/财星/食伤）为用神，位于（月柱/时柱），这说明你在（仕途/财运/技艺）方面有着先天优势……"

### 事业方向话术

> "命局中（杀印相生/官印相生/食伤生财），格局清纯，最适合往（军警/公职/经商/文艺）方向发展。若走对方向，中年以后必有大成。"

### 财运话术

> "八字中财星（旺而逢生/弱而受制），属（富命/普通财运）。目前行（某）大运，正是（聚财/守财/破财）的关键时期……"

### 官运话术

> "官星（为用旺相/为忌受制），先天有（显赫官职/小有职权/无官）之象。待行至（某）大运流年，官星发力，便是升迁良机。"

### 职业变动话术

> "命带驿马且逢冲，一生职业多变，宜动中求财。建议从事（运输/贸易/出差多）的工作，不宜长期固定一处。"
