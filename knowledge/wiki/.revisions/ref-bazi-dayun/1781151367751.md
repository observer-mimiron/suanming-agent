# 第一篇：日主强弱判断

## 一、核心概念

日主（日干）是八字命理的核心，代表命主本人。其強弱決定用神取向，是解讀命盤的關鍵第一步。

## 二、四大判断要素

### 2.1 月令（权重约50%）

月令是判断日主强弱的最重要因素。根据日主五行与月支五行的生克关系，分为五个等级：

| 状态 | 关系描述 |
|------|----------|
| **旺** | 日主五行与月支五行相同（如甲木生于寅月） |
| **相** | 日主被月支所生（如甲木生于子月） |
| **休** | 日主生月支 |
| **囚** | 日主克月支 |
| **死** | 日主被月支克制 |

**得令与失令对照**：
- **木**：得令于寅、卯、辰月（春），失令于申、酉、戌月（秋）
- **火**：得令于巳、午、未月（夏），失令于亥、子、丑月（冬）
- **土**：得令于辰、未、戌、丑月，失令于寅、卯月
- **金**：得令于申、酉、戌月（秋），失令于巳、午、未月（夏）
- **水**：得令于亥、子、丑月（冬），失令于辰、未、戌、丑月

### 2.2 通根（权重约30%）

地支中藏有天干，若藏干与日主五行相同即为「通根」。通根分三个层级：

- **本气藏干**：力量100%，最强之根
- **中气藏干**：力量60%，次强
- **余气藏干**：力量30%，较弱

**通根位置权重**（由高至低）：月支 → 日支 → 年支 → 时支

**范例（日主为甲木）**：
- 寅支藏甲丙戊 → 甲木得本气强根
- 亥支藏壬甲 → 甲木得中气根
- 辰支藏戊乙癸 → 乙木为甲木同五行之根
- 未支藏己丁乙 → 乙木同为甲木之根

### 2.3 透干（权重约20%）

天干中出现与日主同五行（比劫）或生日主（印星）者：
- **比肩、劫财透出**：中等力量
- **正印、偏印透出**：力量较强

**天干位置权重**（由高至低）：月干 → 时干 → 年干

### 2.4 干支配合

三种主要交互关系：
1. **干支同气**：天干与地支五行相同，力量叠加（如甲寅、庚申、癸亥）
2. **干支相生**：地支生天干则日主得生（如甲子、庚辰）
3. **干支相克**：天干克地支为"盖头"（如甲辰），地支克天干为"截脚"（如甲申）

## 三、强弱等级划分

### 3.1 身强

**条件**：月令得令或得生 + 2个以上通根 + 天干有比劫或印星透出 + 生扶力量 > 克泄力量

**特征**：自信独立，能承担压力，适合竞争性工作

**用神方向**：宜泄（食伤）、宜耗（财星）、宜制（官杀）

### 3.2 身弱

**条件**：月令失令或受克 + 通根少（0-1个） + 天干多泄克之神 + 克泄力量 > 生扶力量

**特征**：依赖性强，抗压能力较弱，需要贵人相助

**用神方向**：宜生（印星）、宜助（比劫）

### 3.3 身中和

**条件**：月令不旺不衰 + 少量通根 + 生扶与克泄接近平衡

**特征**：性格平和，适应能力强，发展均衡

**用神方向**：视具体情况取泄或扶

### 3.4 快速判定口诀

```
得令+得地+得势 = 极旺
得令+得地 或 得令+得势 = 身旺
失令+得地+得势 = 身旺（仍有根基）
失令+得地+失势 或 失令+失地+得势 = 身弱
失令+失地+失势 = 极弱
```

### 3.5 量化打分法

```
总分 = 月令分(±50) + 根气分(0~30) + 帮扶分(±10/个) - 克泄耗分(-5~-10/个)

≥ 60 → 身旺
41~59 → 中和
≤ 40 → 身弱
极弱无扶 → 从弱格
极旺无制 → 从旺格
```

## 四、判断步骤

1. **看月令**：确定月支五行，判断日主在月令的旺衰状态
2. **数通根**：查看四个地支的藏干，统计同五行藏干数量，注意本气、中气、余气区别
3. **看透干**：查看年、月、时三干，统计比劫和印星数量，注意位置权重
4. **综合判断**：计算生扶力量总和与克泄力量总和，比较大小得结论

## 五、常见错误

- **只看月令**：虽最重要但仍需综合通根、透干等因素
- **忽视藏干**：地支藏干对判断有重要影响，不能只看表面五行
- **混淆阴阳**：甲木与乙木虽同属木，但阴阳属性不同需区别对待
- **忽视刑冲合害**：地支间的交互作用会影响通根有效性

# 第二篇：大运流年

## 一、基本概念

大运是每十年一运的周期，主导该段时间的总体运势走向；流年则对应每一年的干支影响。

## 二、大运排法

### 2.1 起运岁数

依出生年干阴阳与性别决定顺排或逆排：

| 条件 | 排法方向 |
|------|---------|
| 阳年（甲丙戊庚壬）男 | 顺排 |
| 阳年女 | 逆排 |
| 阴年（乙丁己辛癸）男 | 逆排 |
| 阴年女 | 顺排 |

**计算步骤**：
1. 找出出生日前后的节气
2. 顺排者，计算从生日到下一个节气的天数；逆排者，计算从生日到上一个节气的天数
3. 每3天折合1岁，公式为天数 ÷ 3（四舍五入）

核心：3天 = 1岁，1天 = 4个月，1时辰 = 10天。只用12个"节"，不用"气"。

### 2.2 大运干支排列

起于月柱，顺排者干支各加1，逆排者各减1。以月柱「丙寅」顺排为例：丁卯（5-14岁）→ 戊辰（15-24岁）→ 己巳（25-34岁）→ 庚午（35-44岁）→ 辛未（45-54岁）→ 壬申（55-64岁）→ 癸酉（65-74岁）→ 甲戌（75-84岁）。

## 三、大运分析

### 3.1 十年分段

"前5年"以大运天干为主，"后5年"以大运地支为主。

### 3.2 大运与命盘关系

按五行喜忌分五种等级：用神（大吉）、喜神（吉）、闲神（平）、忌神（凶）、仇神（大凶）。

### 3.3 大运与原局作用

四种基本作用方式：
- **冲**：变动大，可能破坏原有格局
- **合**：增强或减弱某五行
- **刑**：易有灾祸、是非
- **害**：暗中不利、损失

### 3.4 十年大运详解（依十神类型）

- **比劫运**：竞争增加、开支增大。身强者破财；身弱者得助力
- **食伤运**：才华发挥、创意增多。身强者名利双收；身弱者泄气过度
- **财运**：财务机会多、消费增加。男命感情机会亦在此运。身强者财运亨通；身弱者反为财所累
- **官杀运**：工作压力、权力机会。女命感情机会在此。身强者事业有成；身弱者压力过大
- **印星运**：贵人相助、学习机会、名声提升。身强者可能懒散；身弱者大吉

## 四、流年分析

### 4.1 流年与命盘关系

- 流年为用神 → 吉，当年顺利
- 流年为忌神 → 凶，当年多事
- 流年冲命盘 → 变动（工作、住所等变化）
- 流年合命盘 → 缘分（感情、合作机会）

### 4.2 流年十神详解

- **比肩**：新开始、竞争，谨慎投资，人际复杂
- **劫财**：破财机会，竞争激烈，避免合伙
- **食神**：才华发挥，口福增加，适合创作
- **伤官**：创意迸发，是非口舌，感情多变
- **偏财**：偏财机会，投资运佳，桃花机会
- **正财**：正财收入，稳定发展，男命感情稳定
- **七杀**：压力增大，突发事件，防小人
- **正官**：工作晋升，责任增加，女命感情稳定
- **偏印**：特殊机会，学习运佳，防健康问题
- **正印**：贵人相助，文书顺利，名声提升

### 4.3 大运与流年组合判定

| 大运 | 流年 | 结果 |
|------|------|------|
| 吉 | 吉 | 大吉大利 |
| 吉 | 凶 | 吉中有凶 |
| 凶 | 吉 | 凶中有吉 |
| 凶 | 凶 | 需特别注意 |

## 五、重要运势节点

### 5.1 换运年

大运交接年份，运势可能出现明显变化。

### 5.2 太岁年（本命年）

流年地支与年支相同。可能有较大变动，但不一定是凶年，需看整体格局。

### 5.3 犯太岁五种类型

| 类型 | 条件 | 影响 |
|------|------|------|
| 值太岁 | 年支=流年支 | 本命年，变动大 |
| 冲太岁 | 年支与流年支相冲 | 冲突、变动 |
| 刑太岁 | 年支与流年支相刑 | 是非、灾祸 |
| 害太岁 | 年支与流年支相害 | 暗损、小人 |
| 破太岁 | 年支与流年支相破 | 破坏、损失 |

### 5.4 重要流年组合

- **岁运并临**：大运地支与流年地支相同，力量加倍，吉则大吉、凶则大凶
- **岁运相冲**：大运地支与流年地支相冲，变动剧烈
- **岁运天克地冲**：天干相克且地支相冲，极为不利

## 六、运势预测要点

### 6.1 看层次
1. 先看大运 — 决定十年基调
2. 再看流年 — 决定当年吉凶
3. 参考流月 — 决定起伏时间

### 6.2 看组合
1. 大运与原局的关系
2. 流年与原局的关系
3. 大运与流年的关系

### 6.3 盲派应期锁定

| 方法 | 机制 | 示例 |
|------|------|------|
| 填实法 | 原局缺某字，流年填上 | 原局伤官无正官，流年见正官→伤官见官事发 |
| 冲开法 | 原局库被冲 | 财库在辰，戌年冲开→发财或破财 |
| 合动法 | 流年合静宫位 | 流年合夫妻宫→结婚或离婚 |
| 刑动法 | 流年补全三刑 | 原局寅巳缺申，申年补全→官非伤病 |

# 第三篇：婚姻感情

## 一、核心概念

- **配偶星**（天干）：男命看正财（妻）与偏财（情人）；女命看正官（夫）与七杀（非正缘）
- **婚姻宫**：指日支，代表配偶的位置

## 二、婚姻吉利组合

1. **配偶星纯一** — 男仅正财无偏财、女仅正官无七杀，表感情专一稳定
2. **配偶星得位** — 星在日支，缘分深、婚姻稳、易得良缘
3. **日支为用神** — 配偶有助、婚后运势提升
4. **夫妻宫安稳** — 日支不受刑冲，婚姻稳定、能白首偕老

## 三、婚姻不利组合

1. **配偶星混杂** — 男正偏财皆有、女官杀混杂，感情复杂、婚姻不稳
2. **配偶星被合** — 配偶易被吸引，须防第三者
3. **日支逢冲** — 婚姻动荡、夫妻分离
4. **婚姻宫空亡** — 配偶缘分薄、晚婚、感情不稳

## 四、男命关键判断

- **正财**旺则妻缘佳，弱则晚婚，被克则婚姻有阻，被合则妻被竞争
- **偏财**多表风流，透干易外遇，在日支可能再婚
- 比劫夺财："兄弟争妻，感情竞争"
- 财星入墓：妻体弱或晚婚

## 五、女命关键判断

- **正官**旺则夫缘佳，弱则晚婚，被克被合同理
- **七杀**多感情复杂，透干易有情人
- 官杀混杂："婚姻多变"
- 伤官见官："克夫，婚姻不顺"
- 食神合杀：可化解不良姻缘

## 六、日支十神看配偶

- **日坐比肩**：独立但易争执
- **日坐劫财**：竞争关系，防第三者
- **日坐食神**：配偶温和体贴，家庭和睦
- **日坐伤官**：配偶有才华但个性强，女命婚姻不稳
- **日坐偏财**：配偶善交际，可能较风流
- **日坐正财**：稳定踏实，夫妻同心，婚姻美满
- **日坐七杀**：配偶强势、压力较大
- **日坐正官**：女命最佳，端正有礼、婚姻稳定
- **日坐偏印**：配偶思想独特，关系微妙
- **日坐正印**：善良体贴、家庭幸福

## 七、婚姻时机

- 流年见配偶星 → 遇正缘
- 流年合日支 → 动婚姻宫
- 日支被流年冲 → 未婚可能结婚，已婚婚姻变动
- 配偶星透出（藏干转显） → 缘分出现

## 八、桃花星

依年支/日支确定：
- 申子辰见酉
- 寅午戌见卯
- 亥卯未见子
- 巳酉丑见午

年支与时支属"墙外桃花"，月支属"墙内桃花"（正当姻缘），日支为"夫妻桃花"。

## 九、婚姻建议

- 身强者配偶宜柔顺，避免太强势
- 身弱者需借伴侣之力
- 女命官杀混杂宜晚婚、感情专一
- 男命比劫多"需防争夺，感情需用心"

## 十、六大化解方法

1. 选择晚婚（28岁后结婚）
2. 与有婚史之人结婚（化解二婚信号）
3. 选相合属相（优先六合、三合）
4. 配羊刃日之人（以硬配硬）
5. 往喜用方向发展（择偶、安家往喜用方位）
6. 颜色、物品、心态调整
