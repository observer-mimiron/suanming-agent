## 一、六亲星定位（源自《渊海子平》）

以日干为太极，按十神确定六亲。核心原则："星为体，宫为宅"——星代表六亲本人的特质能力，宫代表该六亲的生存环境及与命主的关系。

| 六亲 | 男命取法 | 女命取法 |
|------|----------|----------|
| 父亲 | 偏财（无偏财看正财） | 偏财 |
| 母亲 | 正印（无正印看偏印） | 正印 |
| 兄弟 | 比肩 | 劫财 |
| 姐妹 | 劫财 | 比肩 |
| 儿子 | 七杀 | 伤官 |
| 女儿 | 正官 | 食神 |
| 祖父 | 偏印 | — |
| 祖母 | 伤官 | — |
| 妻子 | 正财 | — |
| 丈夫 | — | 正官 |

> 经典规则：凡男命阴日干论六亲时，皆以阳日干论；凡女命阳日干论六亲时，皆以阴日干论。

## 二、六亲宫位

| 宫位 | 主事 |
|------|------|
| 年柱 | 祖上、父母、长辈 |
| 月柱 | 父母、兄弟、同辈 |
| 日柱（日支） | 配偶（夫妻宫） |
| 时柱 | 子女、晚辈、晚年 |

### （三）子女核心判断法则（源自《子平真诠》）

子女有出息的四个条件（星+宫双看）：
1. 子女星或时干支偏旺但有制
2. 子女星或时干支偏弱但有生源
3. 子女星或时干支太旺但有泄
4. 子女星或时干支旺极，局中全是生扶无克

## 六、宫位吉凶互参法（核心方法论）

判断六亲总体得失的原则：

| 组合 | 含义 |
|------|------|
| 宫吉星凶 | 六亲能力不强，但家庭环境尚可，与命主关系不差 |
| 宫凶星吉 | 六亲有能力，但家庭不睦或身体不好，缘分浅 |
| 星宫皆吉 | 六亲自身好，与命主关系也好 |
| 星宫皆凶 | 六亲自身差，与命主关系差或早逝 |

### 真假星判断

- **真星**：有禄、刃、墓库、长生、帝旺等强根，受生有力 → 六亲有能力，寿命长，缘分深
- **假星**：虚浮无根，或根被破坏 → 体弱多病，早逝，能力平庸，缘分浅薄

## 七、经典六亲歌诀（民间传承口诀）

> 偏财被损先去父，食神重见母早亡。
> 男犯羊刃克先妻，女犯伤官夫早离。
> 伤官见官从灾伤，平生只看女儿郎。
> 倒食临子伤妻母，日干月合丈人亡。

> 年干比肩月干同，偏财不显父早终。
> 年支正财月支见，母亲早丧或离异。
> 日支羊刃再见刃，配偶早丧不用问。
> 月干七杀再见杀，兄弟之中有夭折。

> 注：歌诀类内容属于民间经验总结，不同流派表述可能有差异，解读时应结合命局整体分析，不可机械套用。
