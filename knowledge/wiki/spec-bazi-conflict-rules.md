## 二、资料优先级与使用规则

### 当来源冲突时的引用优先级

```
S 级古籍 > A 级注疏 > B 级验证数据 > C 级参考
```

**具体规则：**

| 冲突领域 | 优先参考 | 原因 |
|----------|----------|------|
| 格局判定 | **《子平真诠》** 优先于《渊海子平》 | 格局法在清代才成熟，沈孝瞻体系最完整 |
| 旺衰判断 | **《滴天髓》** 优先于其他 | 天地人三论、清浊真假的哲学框架最深刻 |
| 调候取用 | **《穷通宝鉴》** 为唯一标准 | 调候论的开山之作，无竞争对手 |
| 神煞查阅 | **《三命通会》** 优先 | 收录最全，且《四库全书》认证 |
| 十神基础 | **《渊海子平》** 为源头 | 子平术的原始定义，后世的根 |
| 综合论断 | **《三命通会》** 覆盖面最广 | 百科全书性质，可补其他古籍之缺 |

### 当同级别来源冲突时的解决规则

1. **年代原则**：后出转精 — 清代注本（任铁樵、徐乐吾）优于明代原文
2. **逻辑原则**：挑逻辑自洽、能解释更多案例的版本
3. **验证原则**：用 MingLi-Bench 或已知真实案例交叉验证

## 三、流派冲突与 AI 决策规则

### 三大流派识别

| 流派 | 特征关键词 | 代表文献 |
|------|-----------|----------|
| **子平格局派** | 月令取格、用神、顺逆 | 《子平真诠》《渊海子平》 |
| **盲派象法** | 宾主体用、做功、铁口直断 | 口传歌诀 |
| **新派量化** | 分数制、用忌二分、百神论 | 李涵辰著作（⚠️争议大） |

### 流派选择矩阵（AI 决策用）

| 用户问题类型 | 首选流派 | 原因 |
|-------------|----------|------|
| 一生富贵层次、事业方向 | **子平格局派** | 准确率82% |
| 具体事件应期（车祸、手术） | **盲派象法** | 准确率89% |
| 流年婚期、跳槽时间 | **新派**（审慎使用） | 准确率85%，但争议大 |
| 性格、健康、六亲 | **子平派** | 最体系化 |
| 验证/考试类问题 | **子平派为主** | MingLi-Bench 基于子平体系 |

### AI 输出时的流派标注规则

```
✅ 必须标注：引用任何断语时标注来源流派
✅ 冲突时说明：明确指出不同流派的结论差异
❌ 禁止做法：不同流派的规则混用（如子平用神 + 盲派做功 + 新派打分）
```

## 四、用神取用时的冲突解决

### 核心规则

```
极端气候 → 调候优先（《穷通宝鉴》「调候为急」）
一般偏颇 → 扶抑与调候兼顾权衡
调候伤身 → 扶抑优先（「顾命要紧」，不可调而丧命）
```

### 判断流程

1. 检查月令：是否存在极端寒暖燥湿？（全盘无火/无水）
2. 若极端 → 调候优先，调候用神为第一用神
3. 若非极端 → 按扶抑法取用，调候为辅助考量
4. 若调候用神恰好严重损伤日主 → 禁止调候，回归扶抑

### 引用依据

- 《穷通宝鉴》：「调候为急」「有杀先论杀，无杀先看调候」
- 《滴天髓》：「天道有寒暖…不可过也。地道有燥湿…不可偏也」
- 《子平真诠》：「八字用神专求月令…亦须配气候而互参之」
- 实战共识：「在不能两全其美时，顾命要紧，以扶抑用神为主」

## 五、资料可信度总评

### 可直接引用（无需验证）

- 天干地支基础数据（五行、方位、藏干、纳音）
- 十神定义与速查表
- 十二长生序列
- 干支合冲刑害关系
- 六十甲子序列

### 可引用但需标注来源

- 格局判定规则（标注来自《子平真诠》）
- 用神取用方法（标注流派）
- 大运排法与起运计算

- 健康疾病断语
- 事业财运断语
- 六亲断语
- 合婚方法

### 谨慎使用（有争议）

- 新派量化打分法
- 部分盲派象法解读
- 任何未标注来源的「口诀」「秘诀」

## 六、AI 知识库更新策略

1. **S 级内容锁定**：古籍原文不可修改，新增引用需标注版本
2. **A/B 级定期校验**：与 MingLi-Bench 交叉验证，发现矛盾及时修正
3. **C 级淘汰机制**：与古籍冲突的内容以降级或删除处理
4. **新资料加入**：需标注来源、流派、与现有资料的冲突点
